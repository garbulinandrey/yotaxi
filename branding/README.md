# Логотип Центральный

logo-central-master.png — PNG высокого разрешения с прозрачностью, подготовленный из предоставленного пользователем логотипа через image generation/editing. Дизайн: золотой круг и чёрная буква Ц.

Для сайта используются механически экспортированные PNG/ICO разных размеров. logo-central.png 256×256 — для шапки/футера и разметки организации. favicon.ico — 16/32/48; PNG favicon — 32/48/96; apple-touch — 180; Android — 192/512. Альфа-канал сохранён.

Архив releases/yotaxi-logo-icons-20261110.zip содержит только графические файлы и manifest. Для применения ссылок на сайте и удаления WhatsApp использовать полный актуальный releases/yotaxi-main-20261110.zip.
